# AList-TVBox T4 Sidecar

将已授权的 AList-TVBox（AT）订阅和本地 Python/JavaScript 插件转换为 T4 接口，
供 FM 影视、TVBox 等客户端使用。以独立容器运行，不修改 AT 的数据库、插件或 Web 页面。

当前版本：**0.3.7**。

- [使用指南](USAGE.md)：导入影视、上传和管理插件、网盘播放、兼容检测与故障排查。
- [部署指南](NAS_DEPLOYMENT.md)：Docker/NAS 部署、源码构建、反向代理、升级与备份。

## 功能

| 功能 | 说明 |
| --- | --- |
| 统一订阅 | 自动读取 AT 订阅，汇总可执行插件和本地插件，提供 `/t4/config.json` |
| 中文管理页面 | 独立 `/t4/` 入口，自动生成可复制的完整订阅和单插件 FM 地址 |
| AT 内置源 | 对接 Bilibili、我的追更、我的云盘、AList、片单、直播等原生服务 |
| AT 插件 | 支持 ATVP raw Python、官方格式加密插件，以及动态 loader/keyring 配置 |
| 官方远程插件 | 识别 AT 官方 T4 插件描述符，转发至 AT 执行，不重复启动本地插件 |
| 自定义插件 | 上传标准 Python、Sidecar JavaScript 或包含依赖文件的 ZIP，自动注册 |
| 插件管理 | 删除、重命名、排序、刷新运行实例、首页检查和复制地址，设置持久保存 |
| 网盘服务端通路 | 可选服务端代理和 AT 内网回源，复用 AT/PowerList 已有网盘配置 |
| 媒体网络交付 | 普通直链携带请求头交给客户端；支持 HLS、内联 DASH 和必要代理转发 |
| 兼容检测 | 批量检查首页、分类、搜索、详情、图片、取链及媒体字节，导出结果 |
| 播放诊断 | 查看请求关联日志、插件错误、网络状态和耗时，导出脱敏日志 |
| 运行资源 | Linux Worker 共享基础库；空闲浏览实例分批退出，冷 ID 和浏览上下文转存临时磁盘 |

## 使用

1. 按部署指南启动容器，只需配置 AT 完整订阅地址。
2. 打开 `http://NAS_IP:8765/t4/`。
3. 点击“复制影视订阅地址”，导入影视客户端的点播配置。
4. 在影视中选择站点使用；上传本地插件后刷新影视配置即可。

无需额外配置 Gateway Token、单插件参数或手工拼接 JSON。AT 原有授权仍由上游负责。

## 适用范围

- 服务端负责订阅读取、爬虫运行、网络请求和结果交付；客户端负责视频解码与播放。
  不转码、不重封装，也不增加额外分片下载层。
- AT 推送保留原生客户端实现，需要支持 JAR 的客户端；纯 T4 客户端不具备此能力。
  WebHome 等页面入口不转换为点播插件。
- Python/JS 插件需要符合支持的运行合同并具备配套依赖，不能保证任意脚本上传即用。
  官方远程插件的可用能力取决于对应 AT 版本。
- 网盘代理不保证比直连更快；当前不承诺全插件兼容、原客户端性能等价或真机长播全部通过。
- 管理入口可执行上传的插件，只应提供给可信用户。完整订阅可能包含原生 AT 推送所需授权，
  不要公开分享；远程访问使用现有 VPN 或有访问控制的反向代理。
