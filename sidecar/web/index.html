健康检查地址
这是 Sidecar 的独立管理入口，不会修改 AT 的页面、数据库或原始插件。T4 客户端调用时使用同一服务的 /t4/api/ 接口。默认本地模式不需要额外令牌；如果部署者主动配置了 T4_GATEWAY_TOKEN，页面会自动显示保护模式。

使用说明

  1. 打开页面后，Sidecar 会自动读取容器中的 source 配置和 AT 订阅，不需要手工拼接订阅参数。
  2. 在每个 source 中点击“读取能力”，页面会读取脱敏后的订阅信息并列出可用插件。
  3. 选择要调用的插件；多插件订阅必须选择对应的 site，例如 csp_BiliBili 或 csp_Media。
  4. 点击“首页冒烟”验证当前插件，或点击“复制 FM 地址”获取该插件的 FM 兼容入口。
本地模式下复制的 FM 地址可直接使用。若部署者启用了可选保护模式，Token 只临时保存在当前浏览器标签页的 sessionStorage 中，复制的 FM 地址会自动绑定插件访问钥匙。

上传本地插件

Python 文件需要包含标准 Spider 类；JavaScript 文件需要导出 homeContent、categoryContent、detailContent、 searchContent、playerContent 等方法。上传后会自动出现在 local-uploaded source。
